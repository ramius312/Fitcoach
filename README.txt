FIT//COACH – Installation
ZIP entpacken. Alle Dateien gemeinsam auf einen statischen HTTPS-Webhost hochladen (z.B. GitHub Pages oder Netlify). Die öffentliche HTTPS-Adresse in Chrome auf Android öffnen, Menü > Zum Startbildschirm hinzufügen / App installieren. Nach erstem Laden online ist die App offline nutzbar. Lokal am PC kann man mit python -m http.server 8000 und http://localhost:8000 testen. Die HTML-Datei allein ist eine Vorschau, keine installierte PWA. Daten bleiben im Browserprofil; regelmäßig exportieren. Keine Cloud-Synchronisation. Nährwerte und Prognosen sind Schätzungen.
